# ArchAngel

Your AI. Your Wallet. Your Rules.

An AI-agent payment guard for NEAR testnet. Review payment requests, set spending limits, manage trusted recipients, and approve or block transfers before signing in your wallet.

## Development

```bash
npm install
npm run dev
```

## Safety

Local policy checks are advisory and are not enforced on-chain. Transactions only occur when the user explicitly signs them in their connected wallet. Never share seed phrases or private keys.
